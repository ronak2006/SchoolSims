# SchoolSims Player

An interactive multilingual simulation platform for leadership training. Learners navigate a realistic workplace scenario across 7 slides — from context and video to a branching decision — in **7 languages**, with **5 selectable character ethnicities**. Designed for colleges and corporate L&D teams.

## Features

- **7-slide branching scenario** — context, text+image, video, decision (A/B), outcome, summary
- **7 languages** — English, Spanish, Arabic, Chinese, Nepali, Swahili, Urdu; content and UI fully localized
- **5 character ethnicities** — African, Caucasian, East Asian, Latin, South Asian (photo + video only; no effect on scenario text or outcomes)
- **Text-to-speech** — optional ElevenLabs integration with file-based caching; falls back silently when no key is set
- **Post-simulation review** — star rating + open feedback form, stored server-side
- **Keyboard shortcuts** — press `[A]` or `[B]` on the decision slide

## Project Structure

```
backend/
  main.py           # FastAPI — scenario assembly, static serving, reviews API
  scenario.json     # All slide content in EN + ES (linked graph)
  tts.py            # ElevenLabs TTS wrapper with MP3 cache
  reviews.json      # Append-only review submissions
  requirements.txt

src/                # React + TypeScript
  components/       # One file per slide + shared UI
  hooks/useSpeech.ts

public/assets/      # Media: {ethnicity}.png, {ethnicity}_{lang}.mp4, captions_{lang}.vtt
dist/               # Built frontend — generated by `npm run build`

tests/
  verify_ui.mjs     # Puppeteer E2E — 15 screenshots across all states
  package.json
```

## Setup

### 1. Backend

```bash
cd backend
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

**Optional TTS** — create `.env.local` at the repo root:

```env
ELEVEN_LABS_API_KEY=your_key_here
ELEVEN_LABS_VOICE_ID=JBFqnCBsd6RMkjVDRZzb   # optional
ELEVEN_LABS_MODEL=eleven_v4                   # optional
```

If no key is set, TTS is silently disabled.

### 2. Frontend

```bash
npm install
```

## Running

### Development (hot reload)

```bash
# Terminal 1 — API on :8000
cd backend && uvicorn main:app --port 8000 --reload

# Terminal 2 — Vite dev server on :5173
npm run dev
```

Vite proxies `/api` and `/tts` to `:8000`. Open **http://localhost:5173**.

### Production

```bash
npm run build                        # outputs to dist/
cd backend && uvicorn main:app --port 8000
```

FastAPI serves the built frontend and all assets from a single process. Open **http://localhost:8000**.

## API Reference

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/options` | Available languages and ethnicities |
| `GET` | `/api/simulation?lang=en&ethnicity=african` | Slide content + media URLs for a session |
| `POST` | `/api/tts/preload` | Pre-generate and cache TTS audio for slide texts |
| `POST` | `/api/scenario/{lang}` | Persist edited scenario back to `scenario.json` |
| `POST` | `/api/review` | Submit a star rating + feedback |

## Scenario Flow

```
Setup → 1 Context → 2 Text+Image → 3 Video → 4 Decision → 5A/5B Outcome → 6 Summary → Restart
```

- **Language** (`lang`): `en`, `es`, `ar`, `zh`, `ne`, `sw`, `ur` — localizes all text, UI labels, and video
- **Ethnicity** (`ethnicity`): `african`, `caucasian`, `east_asian`, `latin`, `south_asian` — changes character photo and video only; no effect on scenario text, role, or outcomes
- **Decision**: Option A commits to the deadline; Option B proposes a phased pilot. The summary reflects whichever path was chosen.

## Scenario Content

All slide content lives in `backend/scenario.json` as a linked graph keyed by language:

```json
{
  "start_node_id": "context",
  "en": { "nodes": { "context": {...}, "decision": {...}, ... }, "ui": {...} },
  "es": { "nodes": { ... }, "ui": {...} },
  "ar": { ... }, "zh": { ... }, "ne": { ... }, "sw": { ... }, "ur": { ... }
}
```

Edit content via `POST /api/scenario/{lang}`, or directly in the JSON file (restart server to reload).

## E2E Verification

Requires the production server running on `:8000`.

```bash
npm run build
cd backend && uvicorn main:app --port 8000

# In a new terminal:
cd tests && npm install
node verify_ui.mjs --headless
```

Writes 15 screenshots to `tests/screenshots/` covering all slides, both decision paths, multilingual combos, and the error/retry state.
